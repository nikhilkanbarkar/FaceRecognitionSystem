ABOUT THE PROJECT

What this system does

This application performs real-time face detection and recognition from a camera stream. Detected faces are converted into ArcFace embeddings and compared against the stored face database using cosine similarity.

When a face is recognised, the dashboard retrieves its profile from person_details.json and displays the person's name, relationship, status, description and available photo.
